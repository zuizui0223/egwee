# LUPF2 — exploratory continuous 2026 field reproductive-index prediction, source-semantics follow-up

**Lock date:** 2026-11-24. A NEW **explicitly exploratory** test, separate from the 2026-11-24 preregistered LUPF1 which must remain `SOURCE_ENDPOINT_INVALID_STOP`. This follow-up was motivated by source data-quality inspection, not an initially confirmatory test. No author-specific AGF intervention effect, genotype SNP effect, genetic rescue or EGWE natural G×I×F validation is estimable.

## Why a different endpoint validity rule is needed

The exact original Figshare `10.6084/m9.figshare.29606180.v1` field workbook has 3,024 design records and a numeric source column `number of seeds` (not `number_of_seeds`). Original LUPF1 requires all observed seed values be nonnegative *integers*; its outcome job stopped under that predeclared rule. Post-stop source-quality audit (run 45328462636) finds 990 missing/NA, 1,881 numeric nonnegative integer, **153 numeric nonnegative noninteger**, and **zero negative values**, plus 982 missing flowering-onset records. Thus the source itself records a non-integer production field. Earlier related Sacristán-Bajo et al. 2025 methods explicitly estimated number of seeds per plant as `number of fruits × mean seeds per fruit`; this can produce fractional values (DOI 10.1111/eva.70087, section 2.3). It is **not yet independently proven** that the 2026 source field has exactly the same derivation. Here it is called *source-stored numerical reproductive-index proxy*, not verified actual individual viable seed counts.

## New exploratory question and fixed design (before opening predictive association)

Among 2026 field source records with a nonmissing finite nonnegative value of `number of seeds` (fractionals **retained as originally stored**, never rounded) AND a nonmissing finite nonnegative `flowering_onset`, does adding flowering onset improve held-out same-season prediction of source reproductive index beyond population + original anonymous line code? This is not an early warning, is not an S-allele or molecular interaction test, and does not identify gene-flow treatment effects.

**Source and key:**
- Original Figshare article 29606180, source file `Lupinus_angustifolius_data_field.xlsx`, `sheet2.xml`. File DOI and archive original checksum included in execution receipt; no raw records published.
- `population` must be FRO/PIC; `line` must be one of C/J/L/R/T/X, **code meaning unknown**; `genotype` is original experimental group label, not sequenced alleles; `id` is a record identifier.
- Preserve **all original 3,024 rows** in denominator; report source core group counts; classify seed and flowering onset missingness independently; do not assume missing==0 or missing at random. Complete cases only are eligible for a conditional predictive endpoint. Do not reassign treatment codes, impute, round, or filter source lines based on effects.
- Source quantitative proxy accepted if numeric finite nonnegative (including decimals); negative or nonnumeric nonmissing values trigger stop. A negative flowering onset triggers stop. Original source strings `NA`, `N/A`, blank, `nan`, `null` considered missing.
- Training/testing and uncertainty group: `population|genotype` source label, five folds `int.from_bytes(SHA256(group) first 4 bytes) %5`; no source genotype group shared between train and test. Minimum 3 groups and 10 test records per fold. Exactly 84 `population|genotype` source groups verified from design-only gate; stop if changed.
- Response `log1p(source-stored number-of-seeds numerical proxy)`. Base M0: intercept + source population PIC vs FRO + literal one-hot line codes J/L/R/T/X versus C. Added M1: exactly one numeric `flowering_onset` predictor, centered/scaled on the training fold. No nonlinear predictor, interaction, model selection, site contrast, SNP or causal interpretation.
- Model is the same deterministic ridge `lambda=1` with unpenalized intercept. Primary metric pooled grouped-fivefold held-out `MSE(M0)-MSE(M1)`; positive with 4/5 positive fold gains is descriptively called `EXPLORATORY_PREDICTIVE_INCREMENT`; otherwise `EXPLORATORY_NO_ROBUST_INCREMENT`. This is **not statistical confirmation** because the follow-up endpoint eligibility was chosen after the first source-data stop.
- Descriptive 95% cluster-bootstrap quantile interval for fixed out-of-fold squared error differences, 1,000 block samples with random seed 20261124; not a valid independent-system bootstrap or retraining uncertainty.
- Report source-eligible N, nonmissing and missing record counts, 153 original fractional recordings, heldout scores and original source SHA, but **no** original individual rows, genotype labels, exact source values or original file redistribution.

**Stop + reporting rule:** do not change predictors, criterion, folds, outcome scale or data inclusion again if this test is negative/stops. If missing/ascertainment or group support undermines interpretation, report `NOT_IDENTIFIABLE` instead of modifying primary specification. Previous LUPF1 stop **must stay visible** and no result can be promoted to a conservation management threshold.

**Independent biology limit:** Original published 2026 paper tested flowering advancement and morphology under field conditions. Added seed-index prediction, even if positive, is an exploratory within-study phenology–reproductive association. To test conservation function specifically requires interaction measures, compatible pollen/paternity, viable offspring recruitment, and independent field populations under a prospective design.
