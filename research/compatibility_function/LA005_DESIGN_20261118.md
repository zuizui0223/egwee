# LA005 prospective mating-proxy / visit site transfer

**Scope: one original programme, original Dryad specimen-to-offspring genotypes, exploratory matched-process test; NOT independent replication of an ecological law.**

The preceding LA001/LA002 studies found no robust four-site improvement in lifetime seed production using taxon-specific visitor observations; LA003/LA004 found partial Table 2 rate reconstruction, a source-only 2014 codebook and unresolved published visit units. The Dryad landing-page file descriptions now clarify the default **array** codes: `BF` bee-fly, `F` other flies, `B` honeybee or carpenter bee, `L` butterflies/moths. A subsidiary 2014 temporal sheet calls `B` Butterfly and `Bf` Bee Fly; we preserve **both provenances**, rather than invent an authoritative global mapping.

**Independent functional question:** does the source-coded effective-guild visit exposure predict **detectable nonmaternal alleles in offspring**, beyond genotype class, year, flowering and a mother-level marker heterozygosity proxy, in entire-site holdouts? This is closer to pollen-mediated mating than total seed count but still **not** compatible pollen deposition, paternity assignment or true outcrossing.

Before opening any cross-maternal marker comparisons, source-only row/ID audits found: 256 field plants, 2014 123 maternal rows and 2015 126 maternal rows, 248 unique maternal source labels, 246 unique field-matched source mothers, with one duplicated 2014 site-3 mother key => at most **245 unambiguously matched mothers**. In 2015 two source mothers do not have an exact field label at the recorded site; there are seven offspring rows in 2014 site 3 whose labels disagree with the preceding maternal block. All these are source-exclusion flags; no fuzzy keys or added mothers. Original offspring rows: 2014 192/235/166/222, 2015 248/252/227/254, six microsatellite loci with 2 alleles/locus; both maternal and offspring rows have at least 4 called loci at schema level.

**Locked endpoint:** in each offspring, a nonmaternal allele is detected if any of at least four jointly typed loci contains an allele absent from both maternal copies; aggregate `k/n` per unique mother, with >=4 typed offspring. This indicator is a **lower bound on detectable outcrossing**, and differs from the original study's multilocus MLTR estimator. A valid outcross can be falsely undetected when paternal allele size matches maternal alleles; genotyping errors may yield false detections. No confirmed seed viability or paternal compatibility.

**Frozen model:** one mother contributes one prediction target. Four whole-site folds, both years left out together. Baseline M0 includes year, SC status, interaction, flowering, and maternal genotype heterozygosity fraction to account partly for marker detection; M1 adds LA001 source AH+BF visitation per open flower-hour. Train-only-standardized unweighted logit(k+.5 vs n-k+.5) ridge lambda 1; held-out Brier mean squared error on mother's raw k/n; positive pooled and 3/4 site-fold gains required. No p-values from offspring pseudoreplication. Do not change thresholds/guilds after child genotypes opened.

This is not a test of natural genetic rescue, a universal functional fragmentation regime, or a new selection mechanism. No raw allele/genotype/plant identifiers go to GitHub.
