# Synchronized mating-compatibility–function: four-programme data source gate

**Status 2026-11-17:** **SOURCE SCHEMA AND KEY SCREEN ONLY**. No new outcome estimates, causal mediation, urban–island convergence or model-to-nature transport are claimed. Biological hypotheses and conclusions from the primary publications are already public; the proposed new contribution would require an independently validated, outcome-compatible joint-state prediction across more than one programme.

## Immediate question

Can we recover `I` = natural visit/pollen delivery, `C/G` = genetically compatible mating, and `F` = direct seed/recruitment function at the **same mother × plant/population × year/cohort grain**, then compare whether mate compatibility adds out-of-sample predictive information beyond pollinator service and population size? Until matched keys are verified, even a statistically convincing population-level association is not a new ecological mechanism.

## Original study inventory

1. **SMF001** *Argentina anserina*: [Dryad 10.5061/dryad.pnvx0k6zm](https://doi.org/10.5061/dryad.pnvx0k6zm), six key original Excel tables among 10 files. Published sampling includes controlled mating across 13 populations, S-allele inferences, pollen-tube metrics and outcross seed counts. **No same-unit natural visitation field is currently established**. The study already reports SI leakiness-associated seed recovery; that is not a new discovery here.
2. **SMF002** *Leavenworthia alabamica*: [Dryad 10.5061/dryad.2pj0j](https://doi.org/10.5061/dryad.2pj0j), field pollinators, S-locus 2014/2015, original greenhouse/field seed outcomes and self-compatibility selection. **Within-plant/year join and treatment consistency unknown** until actual schema/ID audit. Two field seasons are not two independent study programmes.
3. **SMF003** *Rutidosis leptorrhynchoides*: Young & Pickup 2010, [DOI](https://doi.org/10.1111/j.1365-2664.2010.01798.x), seven populations with matched pollen deposition, diallel S-allele/mate availability and seed set in a known published study. Data appear in Figures 1–4; **no publicly accessible structured seven-row outcome dataset has been verified**. This is prior art, not an untested hypothesis.
4. **SMF004** *Spondias purpurea*: Cristóbal-Pérez et al. 2021, [DOI](https://doi.org/10.1016/j.biocon.2021.109007), and existing EGWEE five-site paternity plus adult/offspring genetics. Published visitation/fruit-setting means belong to nested or habitat-level comparisons, **not independently extractable five-site same-mother raw observations** from the current ledger. Cannot force a five-row full-path analysis.

These represent **up to four independent published programmes** but **zero verified, same-core cross-programme pooled effects at this stage**.

## Mechanical Stage 0 (the new workflow)

For SMF001/SMF002 query the primary Dryad REST DOI metadata and archive. If public ZIP export is unauthorized (as in a previous Pyrus source), try the documented version/file metadata route without fabricating URLs. For each accessible whitelisted XLSX, report **only** source SHA256, sheet/header labels and XML row counts; no genetic/phenotype values or maternal IDs may be printed. Third-party workbooks/ZIPs remain only in GitHub runner memory; output only schema and access status. If a source is blocked, record `SOURCE_ACCESS_STOP` without substituting an unrelated mirror.

Stage 1 is **not** activated by a schema receipt alone. After inspecting header semantics, write a separate join-grain protocol (e.g. maternal family and outcross treatment) and freeze before looking at signed endpoint coefficients. Do not repeatedly run re-parameterized tests until a positive result appears.

## Future analysis (design target, NOT run now)

- Within each admitted programme, estimate a biologically defensible direct seed/offspring outcome under a held-out *whole population or maternal plant* CV and preserve the study-level cluster.
- Baseline: function versus density + observed pollen/visit service; added: compatibility/S-locus/mate access and, only if measured, recruitment assurance route. Pollen count must not silently substitute for successful compatible pollen or vice versa.
- Report any unmeasured endpoint or unrecoverable key as `NOT_IDENTIFIABLE`, not a zero coefficient. Environmental and historical covariates may confound observational estimates. Original publication conclusions must not be repackaged as new independent evidence.
- Before any urban/island convergence claim: at least two independent biological systems per origin with identical outcome meaning and out-of-sample system validation. Neither this source set nor existing E1/E2 alone meets that.
