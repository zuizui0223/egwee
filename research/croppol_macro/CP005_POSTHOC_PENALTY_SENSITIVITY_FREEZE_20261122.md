Explicitly created AFTER the CP004 outcome**, which was negative for field-size-only benchmark: 201 original fields, 12 within-study blocks and 10 provisionally blocked sources, 1,758 source outcome-discordant field pairs. - Report source equal M0 and M1 pairwise concordances, source-equal M1−M0, positive/negative/zero source counts, 4,000 full-provisional-source bootstrap percentiles seed 20261123 (internal descriptive uncertainty), all three alternatives together. The primary CP004 bootstrap must retain its own original seed 20261122 and its original score and decision.
- Primary `lambda=0.10` source-equal score **jackknife**: drop one scored source component from the *evaluation mean* while preserving the original ten frozen source-specific fitted models. Report min/max of the 10 remaining-nine source means and count of jackknife means below/above zero. This is a robustness diagnostic, **not** independent ten more ecological experiments, and it does not refit/retune the model or claim source independence.
- A compact summary of the direction: call a result `PENALTY_SIGN_STABLE_NEGATIVE` only if **all three** source equal M1−M0 are negative, and `LEAVE_EVALUATION_SOURCE_OUT_SIGN_STABLE_NEGATIVE` only if all ten original-lambda 9-of-10 means are negative. Otherwise report `SIGN_DEPENDS_ON_PENALTY_OR_SOURCE`; do not select the best penalty.
- Avoid recording raw source component labels, site/field identifiers, original yield/visitor/area numbers, pair outcomes, coefficients by site, or source-level confidential values. Only aggregate metrics may be saved.

A sensitivity finding is explanatory about an **exploratory predictive algorithm**, not a causal inference. The source field-size baseline is weak and source study provenance remains provisional; source-bootstrap may underestimate variation when original sources overlap.
