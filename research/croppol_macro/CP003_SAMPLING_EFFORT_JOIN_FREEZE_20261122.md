## Exact permitted audit and up-front STOPs

1. A **sampling row is one taxon × method observation record**, *not* an independent site, time point, or experimental replicate. Do NOT sum `total_sampled_time`, `total_sampled_area`, `total_sampled_flowers` across pollinator taxa/records. The same effort can be repeated many times in the source table.
2. Only candidate key `(study_id, site_id)` exists in both tables; field level additionally has `sampling_year`. Build the set of original field year rows per key **from all 3,448 field rows before filtering**. A sampling key maps unambiguously to a field year only when there is **exactly one** original field row for that `(study_id,site_id)`. A key repeated over years or crops is **ambiguous**, even if the same yield/visit source label; never pick first row or assume one taxon row is one site. Missing key is unknown.
3. For each source `study_id,site_id`, count number of distinct sampling-method labels after trim/collapse/casefold; `NA`/blank is missing. Bounded output displays only counts, never raw site or method strings. One method + one positive finite `total_sampled_time` repeated identically across records is a **candidate unambiguous field-level effort**. Multiple positive effort values, nonpositive values, missing time mixed with present time, or multiple method labels is **not uniquely field-level**. The analogous rules apply separately for `total_sampled_area` and `total_sampled_flowers`. These are conservative joins, not proof source physical census alignment.
4. Report separate candidate categories per original CP002 direct timed visit frames (strict **452**, area-mass **121**); preserve exact CP002 group/endpoint/method/selector/taxa eligibility. Count existing original field-level time and area, sampling matched keys, candidate uniquely positive time/area/flowers, recovered missing field-level time/area, and disagreements between two source levels where both report numeric positive values. Do not overwrite the original published field file and do not treat sampling flowers as an estimate of standing flower abundance or a confounding covariate. A method-specific sampling time may differ from total field-level time by construction.
5. Report complete original sampling rows, distinct sampling keys, unmatched sampling keys/rows, all-key field-year ambiguity, and how often efforts are repeated across taxa or differ within key. Field/sample equivalence is not certified by matching numbers alone. No biologically estimated relationship is permitted, including correlations among sampling effort and yield/visitation.
6. **Zero effort** is explicitly observed zero, not missing, but cannot support positive-time effort recovery. Nonfinite/negative/invalid source values are excluded from recovery and counted. Numeric tokens and distinctness can be inspected; actual magnitudes, site IDs, taxon IDs, coordinates, raw words, genotype, yielded values and visit rates are **never written** to GitHub or stdout.
7. No field-year imputation from sampling table if source key is ambiguous, no sum of repeated taxa efforts, no join on taxon names, no cross-study fuzzy study name conversion, no raw material redistribution, no effective detection correction without explicit original sampling denominators.
8. Scientific status is `EFFORT_SOURCE_KEYS_AUDITED_NOT_MODEL_ADMISSION` even if source joins succeed. The 452/121 original CP002 frames, independent-source 111 components, and 38/one-component full area-mass baseline remain unchanged. This stage assesses which **effort covariates could be recovered**, not biological effects or confounding control.
9. Fail closed on source or header/hash drift, malformed CSV, uncaught transport failure; save bounded error code and return nonzero CI. Check synthetic fixtures: repeated taxon effort not summed, source same site across years ambiguous, multi-method/source missing conflict excluded, numeric zero not missing, correct eligible CP002 frame rows, no leakage of identifiers.

## Downstream decision

A new separate, clearly **reduced-baseline** field-size-only source-out predictive experiment may be considered if original CP002 permitted ≥6 independent provisional source components with ≥5 unique comparable field-site-year units and within-block baseline variation, **but field size alone cannot control flower density, plant resources, or management**. Only a separately committed outcome-blind score protocol can open yield signs. If sampling effort is mostly duplicated/mismatched, do not call it a recovered site-level covariate and do not reinterpret visitor field rates as raw counts.

No changes to `main`, historical fragmentation syntheses, old CropPol PR #78 observational guild predictability, other QPF/Bat studies, or separate theoretical `egwe`. Draft PR #94 stays unmerged.
