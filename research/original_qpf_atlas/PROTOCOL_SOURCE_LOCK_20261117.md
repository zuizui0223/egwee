# EGWEE original-observation Q–P–F atlas: source-selection and join protocol
Date: 2026-11-17
Status: OUTCOME-BLIND, SOURCE-DISCOVERY FREEZE. Empirical EGWEE only, not theory EGWE.

## Goal

The current five-cluster/17-direct-effect fragmentation corpus and 16-programme I–F translation map use published matched effects. A separate 55-pair SF06 exploratory sensitivity finds no resolved global mean downstream-minus-upstream excess, without negating three resolved local mismatches.

**New question, contingent on source admission:** Does directly measured successful transfer/mate provenance (P) improve held-out prediction of reproductive output (F) beyond observed interaction quantity (Q), independently of site and environmental context? Only undertake a cross-programme quantitative test if >=3 genuinely independent complete Q+P+F programmes with same-unit joins are recoverable.

## Definitions and source constraints

- Q: observed visitation, visits per flower/effort, pollinator abundance, or measured pollen quantity.
- P: directly measured conspecific/heterospecific stigmatic grains, pollen tube success or genetically compatible mating/paternity in the *same source biological frame*. A visitor type or nominal SC/SI label is NOT proof of compatible pollen transfer.
- F: mature seed/fruit set or proven recruitment. Separate hand-pollination assays are not naturally matched F.
- Distinguish same plant/flower, population/year and landscape: nested flowers or individuals are not independent environments.
- Habitat fragmentation, managed agriculture, phenology and mountains are separate exposures. Do not mix these into a fragmentation effect-size meta-analysis.
- Shared 13 Argentina populations in 2024 and 2025 are one source programme, not independent replications.

All primary papers studied components of these relationships. Repeating published coefficients is not an ecological discovery. A new independent cross-programme predictive test would need robust holdout performance and a prospectively defined common estimand.

## Order of gates

0. **Now, before signed outcomes:** official DOI/versions/file inventory; SHA-256 and structural worksheet/CSV headers and physical row counts ONLY on a bounded whitelist. Do not print biological values, individual/genotype IDs or coefficients. Use only source API advertised download links. Explicit SOURCE_ACCESS_STOP if denied. No raw data redistribution.
1. After successful schema retrieval, freeze verified joining keys and actual cohort/year, measurement-class validity, zero/missing/effort treatment, independent landscape holdout, source overlap and endpoints **before** looking at outcome associations.
2. Only if >=3 independent complete Q+P+F programmes with defensible common source-unit/holdout frames: run cross-programme macro predictive analysis. Else maintain narrower original-observation pilot/coverage result and report no general mechanism identified.
3. Results from managed agriculture or phenology are not fragmentation-specific confirmation. Do not select only successful systems, alter a frozen question to chase statistical significance, or count multiple species/plants on the same landscape as independent programmes.
