# Source-verified plant primary-study shortlist — genetic context and realised reproduction
## Separate candidate screening from efficacy analysis, 2026-11-15

**Status: original articles identified and endpoint structures read; not yet an effect-size meta-analysis, genomic SNP dataset or true genetic-rescue prevalence estimate.**

The Clarke et al. (2024) dataset holds **19 animal studies/27 pre–post lines**, with 20 population-size outcomes, four survival and three reproductive-success lines from two animal studies. None passes the strict directly observed *interaction-dependent ecological-function* endpoint requirement based on published aggregate categories alone. See `GATE0_CLARKE_2024_RECEIPT_20261115.md`.

The **better initial biological system is self-incompatible plants**, where the genotype–mate-compatibility–seed-function path is explicitly measurable. But this idea already has strong empirical precedents, particularly `Rutidosis`; the publishable novelty would be meta-analytic generality, moderator effects, and *independent intervention-versus-function* controls, not first discovery of genetic mate limitation.

**Critical non-independence:** `SI001` directly cites `SI002` as prior crossing studies of *the same species*. Whether identical populations/biological observations are reanalysed must be checked by population/site IDs and data tables. **Never count 7 populations + 29 population pairs + crosses as 36 independent studies**; these are programmes with nested/shared population units.

### Existing empirical result that limits the novelty claim

Young & Pickup (2010) explicitly show **S-allele diversity → mating compatibility → seed set** with measured pollen supply. Thus neither “neutral genetic diversity is insufficient” nor “genetic compatibility matters beyond pollinator counts” is a novel first ecological discovery. The new, general question is whether **different genetic and ecological limiting processes are predictively separable across multiple independent biological systems, and which experimental rescue strategy targets the limiting step**.

The SI001 example is an empirical **genetically limited function despite a largely intact interaction service**; it is **not** an observed failed genetic augmentation. The SI002 and SI003 between-population pollination manipulations are **candidate** immediate reproductive-function improvements, not evidence of persistent increase in heterozygosity or multigeneration genetic rescue unless offspring genotypes and longer-term fitness have been followed.

### Next data recovery plan with falsifiers

1. **Source-level SI001 extraction:** obtain seven population-level rows/variances for S-allele count, compatible-mate probability, pollen deposition, seed set and correlated paternity. Preserve same population unit; classify S diversity as an **estimated mating-function variant**, not sequenced SNPs. If only scatterplots are available, label `figure_digitization_required`, not “raw data”.
2. **SI002 extraction:** retrieve 24+5 donor–recipient population pairs, source/target IDs, ploidy, crossing arms and fertilization outcomes with uncertainty. Keep pair sharing / repeated targets as clusters; do not calculate a naïve pair-mean SMD without covariance or a hierarchical structure. Verify S-allele genotype availability independently.
3. **SI003 extraction:** ascertain population count, distinct maternal families, cross-treatment denominators, seed set and offspring fitness; obtain original public supplement/raw data permission as appropriate, and link genetic markers if directly measured. The 13% and 96% quoted are article-reported, **not effect sizes calculated by this programme**.
4. **Independence and taxon extension:** seek other self-incompatible species and controlled pollen/habitat factorials, plus non-SI animal/plant programmes with *actually measured ecosystem-mediated function*. Predefine sampling goal before opening source effect signs; don't select only positive rescue examples.
5. **Quantitative gate:** if ≥ a prospectively justified number of independent real biological programmes with common function estimands exists, fit multilevel meta-regression with study/species/donor-route random effects and small-sample intervals. If not, publish a systematic evidence map and a detailed paired-process case comparison; no numerical common rescue coefficient.
