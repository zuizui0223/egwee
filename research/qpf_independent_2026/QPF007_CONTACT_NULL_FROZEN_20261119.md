## B. New fixed test: actual genetic father connection beyond source parent/offspring marginals

Unit for the PRIMARY test is **outcrossed genotyped offspring** (`mother != father`); every genotyped offspring is a genetic measurement, but inference groups complete experimental sessions rather than pretending children are independent ecology. Original 16 cages/sessions, not 16 independent natural locations.

- Observed statistic `T10`: fraction of all assigned **outcross** offspring whose genotype-assigned mother→father directed pair has strictly positive original `import_nb_visit_co10` contact evidence.
- Eligible parentage rows with missing pair row or missing/non-numeric contact remain in the **denominator** but count as lacking *documented positive contact evidence*, with missing and zero categories **reported separately**, never described as known biological negative contact. This underestimates true contact if missing source frames are non-random.
- Null = **condition on every session's marginal number of outcross genotyped offspring per mother and per assigned father**, and on each original session's number of selfed genotyped offspring (self offspring excluded entirely). Within each session, repeatedly **swap two assigned father labels between two source outcross offspring whose mothers differ**, and reject a swap that would make either father's resulting mate be its own mother. This is an exact-margin, no-self Markov-chain permutation; it preserves the number of offspring assigned to each father and mother, and all observed data availability. Only swap labels within same original session. The null tests pair-identity matching beyond the marginals, not merely random uniform father identity. If a session has fewer than 2 distinct original outcross mothers/fathers or no legal swap, mark nonexchangeable and preserve it; provide information and STOP conditional test if fewer than 12 exchangeable source sessions.
- Fixed null RNG `20261119`, 2,000 recorded complete-corpus conditional swap realizations, 1,500 attempted warm-up swaps per session, 100 attempted swap moves per session between recorded draws. Track acceptance rates and number of exchangeable source sessions. Compute global `T10` each null draw and primary excess `T10_observed − mean(T10_null)`; one-sided conditional MC p `(1+#(T10_null>=T10_obs))/(2001)`; report 2.5%/97.5% null quantiles, **not** a confidence interval for true biological effect.
- Additional **16-session-equal** statistic: unweighted mean source-session observed positive father-contact proportion minus its per-session null expectation. Require at least **12** original sessions with source outcross offspring and nondegenerate outcross assignments. Whole-source-session bootstrap, 2,000 complete-session resamples (seed 20261120) for the difference using the **fixed Monte Carlo per-session null expected scores**. Report interval, positive session count, *no* treating 1,099 child IDs as 1,099 independent experimental populations.
- Define "positive conditional enrichment" for this **one-study exploratory null** only if one-sided p<0.05, whole-session bootstrap lower bound>0, and >=12 of 16 session-specific observed-minus-null gains >0. Otherwise unresolved/negative. Do not tune alpha, carryover, groups or results after opening effect.
