**Important original source discrepancy**: This Figshare v1 file contains **1,168 physically present data rows**, 66 columns, unique original row ids 1…1169 with original id **256 absent**. The original paper describes **1,169 compiled entries** and 294 studies. The physical file contains **293 distinct literal `article_code` identifiers** and 106 distinct species-name strings; a literal `article_code` may not coincide exactly with a bibliographic independent study. We do **not** infer the content of the absent row, fabricate a replacement, equate identifiers with the paper's study count, or claim 1,169 physical rows were analysed. The original source formats each semicolon-separated record as a whole quoted CSV line, with doubled inner quotes (especially coordinate string `"latitude;longitude"`). The checker unwraps this original encoding deterministically before analysing.

Source `SN` measures seed number as reported, **not certified seeds per *existing* fruit** across all articles. FS may be in percent rather than 0–1; signs within source units are unchanged but effect size scales **cannot be pooled with GloPL**.
