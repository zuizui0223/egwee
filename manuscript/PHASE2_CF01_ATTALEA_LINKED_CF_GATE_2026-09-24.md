# CFTQ0171 Attalea linked-publication C-F gate — 2026-09-24

## Programme identity

Programme: `P2_CF01_ATTALEA_HUMILIS_2012`.

Linked sources from the same authors / Atlantic-Forest fragment system:

- Andreazzi et al. (2012), *Journal of Tropical Ecology*,
  doi:10.1017/S0266467412000089 — female reproduction / phenology;
- Andreazzi et al. (2012), *Biotropica* 44:237–245,
  doi:10.1111/j.1744-7429.2011.00782.x — reproductive output, seed dispersal and seed predation.

These publications are treated as **one ecological programme**, never two independent K.

## Source fragments and common frame

The programme contains five source fragments:

- small: AJ-19 ha, VE-26 ha, SH-57 ha;
- large: UN-2400 ha, PA-3500 ha.

In the Biotropica source:

- reproductive-output sampling was not conducted at VE-26 ha;
- the threaded-fruit seed-dispersal experiment was also not conducted at VE-26 ha.

Therefore the only possible direct C-F common fragmentation frame is prospectively fixed as:

- small: AJ-19 + SH-57;
- large: UN-2400 + PA-3500.

Independent unit = **forest fragment**.

All palms, fruiting branches, threaded-fruit stations and individual fruits are nested below fragment.

## Retrospective limitation

This is a retrospective linked-source audit. Published directions were visible before this gate:

- local fruit production is higher in small fragments;
- seed dispersal proportion is lower in small fragments.

The purpose of this gate is therefore not to claim outcome-blind confirmation, but to determine
whether a common fragment-level C-F effect can be reconstructed without inventing lower-level
replication.

## Locked candidate endpoints

If fragment-level values become recoverable:

- C = proportion of experimental fruits dispersed >2 m per fragment;
- F = source fruit production per plant / reproductive-output quantity used in the source fragment
  comparison, on the exact same four fragments.

The endpoint must be source-located and fragment-level before any direct Hedges-g effect is opened.

## Public reporting audit

The public article provides enough information to verify the common four-fragment design and the
opposite source-level directions.

It does **not** expose one authoritative numeric table containing the four fragment-level C and F
values needed for a covariance-aware direct effect:

- seed dispersal is reported with large-fragment group summaries and selected small-fragment means;
- reproductive output is reported through mixed models, group summaries and Figure 1 rather than a
  complete four-fragment numeric vector.

Recovering the missing fragment values would require figure digitization or reconstruction from
lower-level/model outputs.

## Decision

Status: `blocked_linked_four_fragment_CF_values_not_recoverable`.

Direct C-F programme increment: **0**.

This is an effect-unit/data-surface boundary, not an ecological null.

## Process evidence retained

The linked source programme provides a particularly clear **cross-layer reversal**:

- local reproductive output increases in small fragments;
- seed dispersal quantity decreases in small fragments.

Thus fragmentation can improve local source production while degrading movement away from the
source. A one-dimensional deterioration score would erase this sign reversal.

This is retained as a **reproduction–movement trade-off / compensation anchor**.

## No rescue

Do not:

- digitize Figure 1 or dispersal figures;
- attach palm/station-level SDs to n=2 fragments per group;
- include VE-26 in one layer but not the other;
- count the JTE and Biotropica articles as separate programmes;
- use group means as if they were two independent fragment values;
- interpret this process anchor as validation of an EGWE/NEE finite operator.

Reopen only if an authoritative source or author-provided dataset exposes the exact four-fragment
C and F values.
