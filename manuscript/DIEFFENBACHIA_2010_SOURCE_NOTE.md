# Dieffenbachia 2010 source note

This note records the source distinction that determines the ML012 terminal decision.

The same four populations (`F1`, `F2`, `C1`, `C2`) are represented in the programme thesis and the 2010 Heredity article. The thesis provides exact male-gamete assignment fractions and an earlier TWOGENER table. The exact assignment matrix is sufficient to reconstruct the locked C endpoint (pollen immigration = 1 - local assignment).

However, the thesis TWOGENER `N_ep` values are explicitly the unadjusted `1/(2 PhiFT)` representation. The 2010 article changed the pollen-pool calculation by adjusting `Phi_ft` for parental inbreeding and selfing, and defines its final `N_ep` from adjusted `Phi''_ft`. The article reports only the accessible range (1.0 to 2.4) in indexed text; the four population-specific Table 2 cells are not exposed by the accessible representation used in this audit.

Therefore the older thesis values are provenance/sensitivity context only and cannot populate the prospectively locked 2010 G_mating endpoint. No value is back-solved from a plotted point, approximate Fp/tm reading, the reported range, or a guessed rounding rule.
