## CFTQ0166 — Cardiopetalum calophyllum recovered

The open source Table 1 reports fragment-level values for 10 cerrado fragments spanning 2.16–929 ha:

- fragment area and nearest-fragment distance;
- pollinator abundance per flower;
- fruit set, follicle set and seed set per flower;
- plant density.

Because Table-1 values and source directions were visible before the deterministic recovery rule was
written, the analysis is explicitly **retrospective**.

Frozen primary recovery:

- independent unit = forest fragment;
- fragmentation severity = negative log fragment area;
- I = pollinator abundance per flower;
- F = fruit set per flower.

Recovered Fisher-z effects:

- I: **−0.245**
- F: **−1.684**
- residual rho(I,F): **+0.169**
- I − F: **+1.439**
- 95% CI: **[+0.483, +2.394]**
- p = **0.00316**

This is a resolved cross-layer separation: measured beetle-pollinator abundance changes only weakly
toward smaller fragments, while reproductive function collapses much more strongly.

Follicle set (z = −0.941), seed set (z = −1.893, n=9) and nearest-fragment-distance sensitivities
retain the same qualitative I-versus-F geometry.

Cardiopetalum is admitted as the **fifth gradient/generalisation programme** with two primary
Fisher-z marginal effects and zero direct Hedges-g programme increment.

## CFTQ0165 — Anaxagorea direct I-F candidate

The source uses three large (306–388 ha) and three small (6–14 ha) Atlantic-rainforest fragments and
measures beetle pollinator abundance plus fruit/seed set.

A retrospective direct-I-F contract is frozen before fragment-level numeric extraction:

- independent unit = fragment, n=3 versus 3;
- I = all-beetle pollinator abundance per flower;
- F = fruit set per flower;
- seed set is sensitivity only;
- flowers cannot become fragmentation n.

Admission now depends on whether six fragment-level I/F values are recoverable.

## CFTQ0162 — Celtis modified-forest multisite candidate

The source samples 36 sites across six forest-modification types and measures direct visitation plus
fruit set over two years.

This is retained at the full-text estimand gate rather than forced into an ordered fragmentation
gradient. The six forest types may mix disturbance dimensions; EGWEE will admit the programme only
if the source itself supports a response-free reference-versus-modified contrast or quantitative
fragmentation variable.
