## Advance and recovered programme

### CFTQ0142 — Acer miyabei

Nagamitsu et al. (2014) report 21 forest fragments and give forest-level Table-1 values for
nearest-forest distance, seed density, viable-seed proportion and mean seed kinship where genotype
sampling permits.

This candidate is unusual in the current queue because the relevant independent-unit values are
published directly in a table rather than hidden in lower-level observations or inaccessible raw
files.

Because Table-1 values were already visible during the source audit, EGWEE labels this recovery
**retrospective**, not outcome-blind.

The deterministic recovery rule fixes:

- independent unit = forest fragment;
- primary exposure = log distance to nearest forest;
- C = negative mean seed kinship, so higher C means greater gene-flow support;
- F = viable seed density = source seed density × viable-seed proportion;
- source seed density alone and viable-seed proportion alone = endpoint-definition sensitivities;
- common C-F frame determined only by source missingness.

The common frame contains **9 forests**: c, d, f, i, l, m, o, p and q.

Recovered primary Fisher-z effects:

- C: **+0.181**
- F: **−0.00019**
- residual rho(C,F): **+0.590**
- C-F contrast: **+0.181**
- 95% CI: **[−0.543, +0.906]**
- two-sided p: **0.624**

The programme therefore does not resolve a precise C-F separation. It is nevertheless admitted as
the **fourth gradient/generalisation programme** because the effect unit, source table, common frame
and covariance are reproducible.

The endpoint-definition sensitivities are biologically informative:

- seed density alone: Fisher z **+0.763**
- viable-seed proportion alone: Fisher z **−0.268**

Those opposite directions show why reproductive-function definition matters. Neither sensitivity is
allowed to replace the deterministic viable-seed-density primary endpoint after inspection.

Acer contributes **two primary Fisher-z marginal effects** and **zero direct Hedges-g programmes**.
