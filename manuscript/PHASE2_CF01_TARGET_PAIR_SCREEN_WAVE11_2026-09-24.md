## Advance

### CFTQ0103 — southern-Thailand mixed-fruit orchards

Sritongchuay, Kremen & Bumrungsri (2016) used **10 matched orchard pairs**. Each pair contained one
mixed-fruit orchard near tropical forest (<1 km) and one far from forest (>7 km). The source measured
flower visitation and fruit set for rambutan, durian and mango in the same programme.

This is the strongest new direct I-F candidate since ML020 because the exposure is a replicated,
response-free forest-proximity contrast and both biological layers are measured in the same orchard
programme.

A recovery contract is now frozen before orchard-level numerical values are opened:

- independent unit = orchard;
- blocking = 10 source orchard pairs;
- primary exposure = far from forest versus near forest;
- mandatory crop set = rambutan + durian + mango;
- I = flower visitation frequency;
- F = fruit set;
- cave proximity remains secondary context and cannot replace forest proximity for durian;
- the three crops are dependent panels inside one programme and can increment direct I-F by at most
  one programme.

Because the published abstract already reports species-specific qualitative results, the complete
three-crop rule is deliberately strict: EGWEE cannot select only the apparently strongest crop.

No orchard-level effect has been calculated.
