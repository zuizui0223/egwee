# Fragmentation sentinel sufficiency audit — 2026-10-03

## Question

Can the observed qualitative response of interaction / pollen quantity be used as a sufficient stand-alone sentinel for the observed qualitative state of reproductive function under fragmentation?

## Important definition

This audit concerns **evidence-state identifiability**, not latent biological truth.

Categories such as `no_detected_loss` and `higher as a point estimate` retain their evidential meaning. They are not promoted to true zero effects or confirmed improvement.

## Frozen evidence universe

The same 16 independent source programmes used by the translation-map audit:

- 8 quantitative matched I–F programmes;
- 8 non-overlapping qualitative-blocked programmes with source-explicit I/F geometry.

Evidence tiers remain separate and no category frequency is interpreted as ecological prevalence.

## Minimal monotone sentinel expectation

A simple monitoring rule would assume that a lower interaction signal maps to a lower reproductive-function state.

The frozen evidence map contradicts that one-to-one rule at the level of observed evidence states.

### When interaction is lower

Observed F states include:

- `lower`;
- `higher` as a point estimate;
- `no_detected_loss`.

Thus the observed state `I = lower` does not identify one F state.

### When no interaction loss is detected

Observed F states include:

- `no_detected_loss`;
- `lower`.

Thus absence of detected interaction loss does not identify reproductive resilience.

### When interaction is higher

Observed F states include:

- `lower`;
- `similar`.

Thus a favourable interaction signal does not identify favourable reproductive function.

## Structural conclusion

> **Within the frozen evidence universe, interaction quantity is not a sufficient state variable for reproductive function: each represented upstream evidence state is compatible with more than one downstream functional state.**

This is stronger than saying that the correlation is imperfect. It is an observed many-to-many response-translation structure.

## Two diagnostic error modes

### False reassurance

Interaction looks intact, elevated or weakly affected while F is worse.

Strong quantitative anchors:

- *Eucalyptus wandoo*;
- *Cardiopetalum calophyllum*;
- Kakamega *Acanthopale pubescens*.

### Apparent over-warning

Interaction looks worse while F is retained, not detectably lower or positive as a point estimate.

Examples:

- Sevenello LARO/POAR;
- Toronto common milkweed;
- *Haloxylon ammodendron*;
- *Caragana korshinskii*.

These names illustrate existence; they are not counted as independent confirmation of one mechanism.

## Why the result can coexist with global positive coupling

A positive cross-species association between pollination and reproductive responses describes average tendency.

Sentinel sufficiency is a different property. A variable can correlate positively with F across many systems yet still fail to uniquely identify F in an individual system.

Thus there is no contradiction between:

1. broad directional coupling in global meta-analysis; and
2. non-identifying translation in matched systems.

## Conservation interpretation

Interaction monitoring can still be valuable for diagnosing pressure on ecological processes.

But a quantity-only interaction indicator should not be interpreted as a sufficient functional state indicator without a downstream reproductive measure or an independently validated conversion model.

## Mechanistic hypothesis

The missing conversion variables most directly suggested by external evidence are:

- pollinator identity/effectiveness;
- compatible versus self pollen;
- realised donor diversity/outcrossing;
- post-pollination filtering;
- reproductive assurance or direct resource limitation.

The current quantitative I–F set measures direct effective-mating quality in 0/8 programmes.

## Claim ceiling

Allowed:

- observed interaction evidence state is non-identifying for F in the frozen 16-programme map;
- both false-reassurance and apparent-over-warning modes exist;
- global average coupling does not imply programme-level sentinel sufficiency;
- multi-stage monitoring is required if reproductive function itself is the management target.

Not allowed:

- exact biological F state is unknowable from all possible interaction measurements;
- category frequencies estimate error rates;
- no-detected-loss is true zero effect;
- interaction monitoring has no conservation value;
- one mechanism explains all translation failures.
