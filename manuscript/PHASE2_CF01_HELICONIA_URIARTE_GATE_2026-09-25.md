# CFTQ0204 Heliconia acuminata C-F gate — 2026-09-25

## Candidate

Programme identity: `P2_CF01_HELICONIA_URIARTE_2010`.

Primary source: Uriarte et al. (2010), *Ecology* 91:1317–1328,
doi:10.1890/09-0785.1.

The source uses ten mapped 0.5-ha plots:

- four plots in 1-ha forest fragments;
- six plots in continuous forest.

It explicitly models seed production, dispersal and seedling establishment.

## What is recoverable

The public article reports plot IDs and Table 3 gives, for all ten plots:

- number of inflorescences;
- **estimated** seed production;
- production limitation;
- model-estimated dispersal limitation;
- seedling establishment limitation.

This makes the source a strong fragmentation process dataset.

## Why it does not enter direct C-F

The Table-3 seed-production quantity is not observed fruit/seed output. The source constructs
potential production by assuming **20 fruits × 3 seeds per inflorescence**, then uses this potential
seed supply inside the recruitment/limitation model.

Under the frozen EGWEE layer contract:

- dispersal limitation can inform C/process evidence;
- seedling establishment belongs to D/resource-demography;
- assumed potential seed production is not promoted to direct realised
  `F_reproductive_function`.

Promoting the modeled potential quantity to F only because it is available for all ten plots would
change the endpoint definition after screening.

## Decision

Status: **retain C-D / seed-limitation process anchor; close direct C-F for lack of an observed
reproductive-function F endpoint**.

No C-F Hedges-g effect is calculated.

## Reopening condition

Reopen only if an authoritative source provides realised plot-level fruit or seed production on the
same ten-plot fragmentation frame. Inflorescence number alone, or potential seed output generated by
the fixed 20×3 assumption, is insufficient.

## No rescue

Do not:

- relabel seedling establishment as F;
- relabel modeled potential seed supply as observed reproductive output;
- count quadrats, plants, seedlings or simulated dispersal events as fragmentation n;
- use the source's null fragmentation result as evidence of layer equivalence;
- use this process model to validate a finite EGWE/NEE operator.
