# Parkia biglobosa Phase-2 recovery result — 2026-09-19

## Admission

The four-population Lompo et al. (2020) system is quantitatively recoverable under the Phase-2 direct-effect contract.

- fragmentation group: cotton populations (CP) = Walley, Vouza;
- reference group: non-cotton populations (NCP) = Saki, Cassou;
- independent unit: population;
- independent n: 2 CP versus 2 NCP;
- lower-level trees, embryos, loci, maternal families and paternity events remain nested.

This is a **retrospective external recovery** because the public source tables were visible before the recovery contract was committed. No prospective outcome-blind claim is made.

## Recovered marginal effects

All effects are CP minus NCP and oriented so positive values mean greater biological support under the more fragmented CP condition.

- C, NMπ pollen immigration: `g = -0.19975047`, `V = 1.00498753`, 95% CI `[-2.16459606, 1.76509513]`.
- G_adult, mature large-tree `H_O`: `g = +1.61624407`, `V = 1.32653061`, 95% CI `[-0.64114662, 3.87363476]`.
- G_offspring, embryo `H_O`: `g = +0.95238095`, `V = 1.11337868`, 95% CI `[-1.11570956, 3.02047147]`.

The signs are not interpreted as evidence that fragmentation improves genetic state. With only two populations per exposure group the standardized estimates are imprecise, and the source itself reports high, broadly similar genetic diversity across the four populations.

## Adult-versus-offspring response geometry

The same four populations support a paired dependence reconstruction.

The within-group residual correlation between mature-adult and embryo `H_O` is `rho = 0.70710678`, giving sampling covariance `0.85934013`.

For the predeclared Phase-2 contrast:

`G_adult - G_offspring = 0.66386312`

with:

- variance `0.72122904`;
- SE `0.84925205`;
- z `0.78170329`;
- two-sided `p = 0.43438897`;
- 95% CI `[-1.00064031, 2.32836655]`.

Thus this system does **not** resolve an adult-versus-offspring fragmentation-response separation. It is still useful because it adds an independent same-exposure cohort programme without selecting for a positive state-separation result.

## Phase-2 consequence

If admitted to the expansion ledger, Parkia increases direct `G_adult-G_offspring` programme coverage from **1 to 2**. The preregistered quantitative opening gate remains **5 independent programmes**, so the cohort-lag meta-analysis remains closed.

The source also provides a directly recoverable C layer, but no F layer, so Parkia does not increase the current C-F or I-F pair counts.
