# Exploratory transition-filtering audit — 2026-09-27

## Status

**Post hoc / hypothesis-generating only.**

This audit was defined after the g-versus-lnRR scale sensitivity was observed. It is not a preregistered test and must not be used to replace the failed scale-invariant separation headline.

## Question

Do proportional fragmentation responses suggest that effects are attenuated, amplified or delayed as they pass across biological transitions or cohorts?

For a pair of negative oriented lnRR effects, the descriptive transmission ratio is:

`T = |lnRR_downstream| / |lnRR_upstream|`.

`T < 1` is labelled attenuation, `T ≈ 1` approximately proportional transmission, and `T > 1` amplification. These are descriptive labels only; no threshold test or pooled transmission model is fitted.

## Observed patterns

### Mating/connectivity to downstream performance

- *Brosimum alicastrum*: C = -0.537, progeny vigour = -0.204, T ≈ **0.38**.
- *Eucalyptus socialis*: mating support = -0.897, family growth = -0.056, T ≈ **0.063**.

Both systems therefore suggest attenuation from mating/connectivity disruption to downstream performance.

### Interaction to reproduction

The Chaco programme shows the opposite pattern:

- *Atamisquea*: I = -0.222, F = -0.251, T ≈ **1.13**;
- *Cercidium*: I = -0.179, F = -0.268, T ≈ **1.50**;
- *Prosopis*: I = -0.125, F = -0.560, T ≈ **4.49**.

Thus interaction-to-reproduction effects can be approximately proportional or amplified rather than attenuated.

### Legacy adult state versus new cohorts

In *Spondias purpurea*:

- adult H_O = -0.154;
- juvenile H_O = -0.536, |juvenile/adult| ≈ **3.49**;
- seed H_O = -0.397, |seed/adult| ≈ **2.59**.

This is consistent with a cohort-lag / legacy-buffering hypothesis in which standing adult genetic state retains older conditions while newer cohorts reflect more recent fragmentation-associated mating.

### Serapias

*Serapias* pollen immigration and fruit set are nearly proportional on lnRR (C=-1.157, F=-1.102, T≈0.95), while adult H_O is less negative (-0.650). This supports the possibility of slower adult-state response, but the comparison is not a temporal experiment.

## Ecological synthesis

The current data do **not** support one monotonic upstream→downstream gradient.

They instead motivate a broader hypothesis:

> **Fragmentation effects are filtered by biological transition and response timescale: some transitions attenuate perturbation, some amplify it, and slow legacy states may lag newer cohorts.**

This is more consistent with the recovered systems than a universal bottleneck ordering.

## Fresh test

A prospective test should predefine transition classes before opening outcomes:

1. interaction quantity → effective mating;
2. effective mating → reproductive output;
3. reproductive output → offspring performance/recruitment;
4. legacy adult state → new cohort state.

For each transition, use one declared effect scale and estimate the paired change on the same sites/populations. Cross-transition attenuation/amplification should not be inferred by mixing unrelated endpoint scales after results are known.

## Claim ceiling

Allowed:

- the current lnRR sensitivity contains examples of attenuation, amplification and cohort contrast;
- transition-specific filtering is a plausible ecological hypothesis for fresh validation;
- no universal monotonic gradient is established.

Not allowed:

- fragmentation effects generally attenuate downstream;
- cohort lag is confirmed across systems;
- the transmission ratios are comparable as a global common-effect parameter;
- these post hoc patterns rescue the current manuscript as a confirmatory macroecological discovery.
