## Advance

### CFTQ0030 — Brassica rapa / Guatemala agricultural highlands

The source defines six independent landscape sites:

- 3 Highly Modified (HM) sites retaining <10% original forest cover;
- 3 Moderately Modified (MM) sites retaining >15% original forest cover.

Each site contains 3–5 experimental plots, each with 36 randomized B. rapa plants. Direct flower-visitation measurements and fruit set are recorded in the same experimental-plot hierarchy.

This advances because the exposure is source-defined from forest-remnant land cover and the same system contains direct I and F measurements. Quantitative recovery must keep **site** as the landscape independent unit; plots and plants remain nested.
